# Code of Conduct

This project is solo-maintained and community-friendly.

## Expected behavior

- Be respectful and constructive
- Assume good intent
- Give actionable feedback
- Keep discussions focused on the code and ideas

## Unacceptable behavior

- Harassment, personal attacks, or hate speech
- Doxxing or threats
- Spam or intentionally disruptive behavior

## Enforcement

I may edit, hide, lock, or remove comments/issues/PRs that violate this policy.
